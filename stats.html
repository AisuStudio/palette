Visit analytics

Cookie-free, storage-free measurement of this board: where visitors arrive from, how long they stay, and which project carousels they open.

Channels

Referrer hostname only — never the full URL, so nothing about the visitor's search or path is kept.

Time on page

Counts only the time the tab was actually visible, so a page left open in the background does not read as attention.

Carousels opened

One event per arrow or dot click, attributed to the project row it sits in.

No cookies, no localStorage, no sessionStorage — the visit id lives in memory and dies with the page.
No IP address and no user-agent string is stored; the referrer is reduced to its hostname.
Returning visitors are therefore not recognisable, and no visitor can be re-identified from this data.
